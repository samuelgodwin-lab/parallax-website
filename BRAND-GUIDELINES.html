02 // Logo

Wordmark & Usage

The Parallax wordmark is set in Bricolage Grotesque 800 at letter-spacing: -0.045em. The full stop after "Parallax" is set in the brand accent. It is a required part of the mark.

On Accent
Do
  • Always include the full stop — it is part of the mark
  • Use white on dark backgrounds, black on light backgrounds
  • Maintain clear space equal to the cap-height on all sides
  • Scale proportionally — minimum 80px wide in digital
  • Use the accent colour only for the full stop character
Don't
  • Remove the full stop or change its colour
  • Stretch, rotate, or distort the wordmark
  • Place on busy, low-contrast, or photographic backgrounds
  • Add shadows, outlines, gradients, or effects
  • Alter letter-spacing or font weight

06 // Motion

Motion & Animation

Motion is intentional and architectural — never decorative. Ease-out for all entrances and hover responses. Ease-in-out for layout shifts and state changes. Scroll-reveal for content sections. No bouncing.

07 // Voice

Voice & Tone

How Parallax speaks. Direct, authoritative, specific. We write like someone who has done this at scale. Think Stripe blog, Figma blog — not generic Medium posts. No throat-clearing. Lead with the point.

Direct
No hedging, no preamble, no buzzwords. The first sentence should carry weight. If you cut it and the paragraph still makes sense, cut it.
"Brand that doesn't perform is decoration."
Authoritative
We speak from experience with BMW, Biblica, Sportradar. Reference specific outcomes and real numbers. Vague confidence is not confidence.
"We reduced time-to-conversion by 40%."
Specific
No generic advice. Genuine expertise, not content marketing. Give the reader something they can act on in the next hour.
"Fix the commissioning process and 70% of the drift disappears within two quarters."
Write Like This
  • "We engineer brand systems that perform under pressure."
  • "Your brand should work as hard as your product."
  • "Fix the governance and the drift disappears."
  • "We don't redesign. We rearchitect."
  • "Parallax has built brand systems for BMW, Biblica, and Accenture."
Never Write This
  • "We're passionate about creating beautiful experiences."
  • "Our innovative solutions leverage cutting-edge methodologies."
  • "We'll make your brand pop!"
  • "As a leading agency, we believe design matters."
  • "Let's circle back on the deliverables going forward."

10 // Imagery

Photography & Imagery

When photography is used it should feel architectural — not decorative. Case study images are the primary imagery format. All bento tile images use object-fit: cover with defined aspect ratios.

01
Architecture Over Lifestyle
Product photography, signage in context, environmental brand shots. Not people smiling at laptops. Not stock handshakes. Show the system operating in the real world.
02
Bento Aspect Ratios
Every image has a defined ratio: 16/7 (lead), 7/5, 1/1, 4/5, 3/2. Never crop arbitrarily. Images must look intentional inside their tile. Use object-position to control the focal point.
03
Dark Overlay on Hero
Hero images always use a gradient scrim: linear-gradient(to bottom, transparent 30%, rgba(0,0,0,0.75) 100%). Ensures title legibility regardless of image content.
04
Video via Vimeo
Case study videos are hosted on Vimeo (unlisted) and embedded via iframe. Stored as URL in the CMS — not as file uploads. Video replaces the lead tile in applications and digital sections.

12 // Implementation

Build Notes

Rules and patterns for engineers and developers building on top of the Parallax system. These are the conventions that keep the system coherent as it scales.

Always
  • Use CSS custom property tokens — never hardcode colour or spacing values
  • Use oklch() for all colour in CSS — it's the authoritative format
  • Apply font-synthesis: none to prevent faux bold/italic
  • Use clamp() for fluid type and spacing — no fixed breakpoints for copy
  • Left-align all headings — centred headings only for pull quotes
  • Add -webkit-font-smoothing: antialiased to body
Never
  • Introduce border-radius on structural tiles, buttons, or bento cells
  • Add a third typeface — Bricolage + JetBrains only
  • Use animations with bounce or spring easings
  • Centre-align hero or section headings
  • Use hardcoded hex values — always go through the token system
  • Use the accent colour as a large background fill
Heading Highlight Syntax (CMS)
  • Wrap the accent word in *asterisks* in any heading field
  • Example: A mark built to *endure.*
  • One highlighted word per heading maximum
  • Prefer the last word or most impactful noun
  • Renders as <em> tag in accent colour
Image Slot Keys (CMS)
  • img_hero — Full-viewport hero background
  • img_identity_mark_01/02/03 — Cycling logo marks
  • img_identity_construction — Logo construction
  • img_identity_variant_light/dark/accent
  • img_app_* — Applications bento slots
  • img_digital_* — Digital section slots
